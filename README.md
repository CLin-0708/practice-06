## 项目简介
本项目围绕“校园生活”主题，使用 jQuery、原生异步 Fetch 及数据可视化图表库（ECharts、Chart.js），构建了一套面向云南大学校园自习室资源的实时监控与分析数据看板。

### 核心功能与技术特色
1. **异步数据加载与四状态设计**：通过原生 `fetch` 与 `async/await` 读取本地 JSON 数据，具备“加载中”、“成功”、“加载失败”与“暂无数据”四状态容错拦截。
2. **宏观统计卡片**：自动聚合计算全校自习室总数、总座位数、当前在座人数与总体在座率。
3. **ECharts 柱状图**：按楼栋对比总座位与占用座位数量。
4. **Chart.js 环形图**：展示自习室开放、维修与闭馆状态分布比例。
5. **jQuery 动态交互**：实现多楼栋分类筛选与卡片点击高亮。
6. **三项独立研究任务**：
   - 任务一：`Promise.all` 双数据集并行加载性能对比研究。
   - 任务二：ECharts 图表事件监听与自习室明细卡片联动研究。
   - 任务三：误导图表（截断坐标轴）修复对比案例分析。
